# OCCT Shape Healing — wire/face repair doctrine (TKShHealing)

Sources read (2026-07-24): `src/ModelingAlgorithms/TKShHealing/ShapeFix/{ShapeFix_Wire.cxx (4478L), ShapeFix_Wire_1.cxx (2005L), ShapeFix_Face.cxx (3259L), ShapeFix_Shape.cxx, ShapeFix_Edge.cxx, ShapeFix_IntersectionTool.cxx}` + `ShapeAnalysis/{ShapeAnalysis_Wire.cxx (2599L), ShapeAnalysis_Edge.cxx, ShapeAnalysis_Surface.cxx, ShapeAnalysis_WireOrder.hxx}`.

Scope: the robustness layer OCCT runs on dirty industry input (STEP/IGES) BEFORE booleans ever see it. Complements (does not duplicate):
- `kb/occt_tolerance-model.md` — tolerance semantics this layer exploits (grow-only, vertex ⊇ edge ⊇ face).
- `kb/occt_pavefiller-core.md` — boolean-side pave/PutToBoundary; healing is the pre-boolean analog.
- `kb/occt_ssi-walking.md`, `kb/occt_builder-assembly.md`, `kb/occt_interference-vef.md`, `kb/occt_ff-posttreat-samedomain.md`, `kb/occt_history-gf-scale.md`.

Architecture rule (ShapeFix_Wire.hxx:39-86): every fix is split into an **analysis predicate** (ShapeAnalysis_*, read-only, sets status bits + measured gaps) and an **action** (ShapeFix_*, consumes the predicate's DONE/FAIL bits). Three repair currencies, tried in fixed preference order: (1) grow a tolerance, (2) edit geometry (shift/trim/bend a curve), (3) edit topology (add/remove/replace edge or vertex). Mode flags: `-1` = default-on-when-sensible (`NeedFix`), `0` = off, `1` = forced.

## STAGE PIPELINE

### Level 0 — shape dispatch: `ShapeFix_Shape::Perform` (ShapeFix_Shape.cxx:83)
1. `ShapeFix::FixVertexPosition` (mode default OFF, `myFixVertexPositionMode=0`).
2. Dispatch by type: COMPOUND → recurse children (SameParameter deferred); SOLID → `ShapeFix_Solid::Perform`; SHELL → `ShapeFix_Shell::Perform`; FACE → `ShapeFix_Face::Perform` (with `ModifyTopologyMode=true`); WIRE → `ShapeFix_Wire::Perform` (ClosedWireMode from `S.Closed()`); EDGE → `ShapeFix_Edge::FixVertexTolerance`.
3. `ShapeFix::SameParameter(myResult, enforce=false)` (whole-shape re-parametrization pass).
4. `myFixVertexTolMode`: if result has >1 face, re-run `ShapeFix_Edge::FixVertexTolerance(E,F)` for every edge of every face — vertices shared across faces must cover ALL faces' representations (bug 0025455).

### Level 1 — face: `ShapeFix_Face::Perform` (ShapeFix_Face.cxx:345)
Order is load-bearing; wire fixes run in TWO passes with different sub-fixes masked:
1. **Wire pass 1** (per wire, `FixLackingMode=off`, `FixSelfIntersectionMode=off`): reorder/small/connected/edge-curves/degenerated/closed. Auto-precision (skl OCC21623): `newpreci = min(preci, ShapeFix::LeastEdgeSize(S)/2) * 1.00001` — precision is clamped to half the smallest edge so small edges don't get eaten by the gap fixer.
2. `FixPeriodicDegenerated` (conical-loop special case, ShapeFix_Face.cxx:3101).
3. `FixMissingSeam` (ShapeFix_Face.cxx:1722) — may split the face; everything after loops over resulting faces.
4. **Wire pass 2** (per wire, `FixSmall/FixConnected/FixEdgeCurves/FixDegenerated=off`): reorder + **FixLacking + FixSelfIntersection** now allowed (they need valid curves+order from pass 1). Then `FixLoopWire` (multi-loop vertex split, :2478).
5. If any wire reported `StatusRemovedSegment` → static `SplitWire` (:242): re-chain edges by shared vertices into separate closed wires; closure verified in 2d with `maxRes = 2*max(UResolution(tol), VResolution(tol))`.
6. `FixWiresTwoCoincEdges` (:2829), `FixIntersectingWires` (:2821, wire-vs-wire via ShapeFix_IntersectionTool).
7. `FixOrientation(MapWires)` (:1165) — outer/inner classification + reversal.
8. `FixAddNaturalBound` (:876) — sphere/torus/periodic surface with no outer bound: add natural boundary; free-interval bookkeeping via `CutInterval`/`FindBestInterval` picks the seam-shift that avoids all holes.
9. `FixSplitFace` (if >1 independent outer wire).
10. Per resulting face: `FixSmallAreaWire(removeFace)` (:2331, uses `ShapeAnalysis_Wire::CheckSmallArea`).

### Level 2 — wire: `ShapeFix_Wire::Perform` (ShapeFix_Wire.cxx:297)
Documented optimal order (hxx:264-271 "NOTE: most fixing methods expect edges ordered → FixReorder first"):
1. `FixReorder` — `ShapeAnalysis_Wire::CheckOrder(sawo, isClosed, mode3d, modeBoth)` (SA_Wire.cxx:593) fills `ShapeAnalysis_WireOrder` with per-edge (start,end) points (3d from vertices, 2d from pcurve ends); greedy nearest-end chaining; status: 0 ok, 1 reordered, -1 reversals needed, 3 only shifted (rotated closed wire), ±2 gaps remain, ≤-10 fail. Both-periodic surfaces use miscible 2d+3d mode (`FixReorder(theModeBoth)` :487). After reorder failure, FixSmall gets `lockvtx=true`.
2. `FixSmall(lockvtx, precsmall=MinTolerance)` — iterates DOWN (`i=NbEdges..1`) so removals don't shift indices. Predicate `CheckSmall` (SA_Wire.cxx:765): edge is null iff `dist(V1,V2) <= prec` AND midpoint of curve (3d, else 2d→surf) within `prec` of both ends. DONE1 = same vertex (free removal), DONE2 = distinct vertices (only removed if `!lockvtx && myTopoMode`, then `FixConnected` re-welds at the removal site). Degenerated edges with pcurve are exempt. On success retries `FixReorder`.
3. `FixConnected` (:557 API / :1476 unit) — predicate `CheckConnected` (SA_Wire.cxx:693) with escalating verdict ladder: `d <= gp::Resolution()` → DONE1 same-point; `d <= myPrecision` → DONE2; `d <= prec` (caller tol, `-1`→MaxTolerance) → DONE3; else try distance to the REVERSED end of E2 (detects missed reversal, FAIL2). Action: DONE1 → reuse one existing vertex; DONE2/3 → `ShapeBuild_Vertex::CombineVertex(V1,V2, 1.0001)` = weighted-average point, tolerance = 1.0001 * covering radius; both old vertices Context()->Replace'd, edges rebuilt by `CopyReplaceVertices`. Runs backward over the wire, refreshing the n-2 slot from context each step.
4. `FixEdgeCurves` (:600) — grouped per-edge sub-fixes in order: `ShapeFix_Edge::FixReversed2d` (2d curve direction vs 3d, via `CheckCurve3dWithPCurve` cross-distance test SA_Edge.cxx:429: reversed iff `d(3dA,2dB)+d(3dB,2dA) < d(3dA,2dA)+d(3dB,2dB)`); `FixRemovePCurve` (forced only); `FixAddPCurve` (projection `ShapeConstruct_ProjectCurveOnSurface`; **singularity split**: if projector reports DONE2, project every surface singularity onto the 3d curve (`SAC.Project < max(Preci,MinTol)`) and split the edge at those params — "edge going over singularity"); over-degeneracy repair when whole wire's 2d displacement ≈ URange (`|Σ| - URange| < 0.1*URange` → re-project with AdjustOverDegenMode=false); `FixRemoveCurve3d`/`FixAddCurve3d` (edge with neither curve → REMOVE edge + FixConnected/FixClosed at the hole); `FixSeam(i)` (predicate `CheckSeam` SA_Wire.cxx:839: `SelectForwardSeam` returns 2 → swap the two pcurves of the closed edge, `B.UpdateEdge(E, C2, C1, Face, 0.)`); `FixShifted` (:1661, below); `FixSameParameter` per edge (with SameRange repair + `CheckPCurveRange` pcurve-outside-basis-domain → re-project); `FixVertexTolerance` per edge.
5. `FixDegenerated` (:1034/:2130) — predicate `CheckDegenerated` (SA_Wire.cxx:896): `precFirst=min(prec,tolV)`, `precFin=max(prec,tolV)`, `precVtx = (prec<tolV ? 2*precFin : precFin)`; if `d(V1,V2)<=precFirst` and a surface singularity is within `precVtx` → edge IS degenerate (dgnr, guard: 3d midpoint must also be near pole or closed-edge false positive); else if `d(V0,V1)<=precFin` and singularity nearest (min-gap of all singularities) → degenerate edge MISSING (lack). 2d span check kills no-ops: skip if `d2d(p2d1,p2d2) <= max(URes(prec),VRes(prec)) + gp::Resolution()`. Action: build degenerated edge = `Geom2d_Line(p2d1, dir(p2d1→p2d2))`, range `[0, |vec2d|]`, `B.Degenerated(true)`, insert (lack) or replace (dgnr). Duplicate consecutive degenerated edges removed (:1050).
6. `FixNotchedEdges` (:3977) — predicate `CheckNotchedEdges` (SA_Wire.cxx:1864): two adjacent edges form a notch (spike) iff tangents at the common vertex are anti/parallel within **0.1 rad** and `d2d <= Tolerance`; identify which edge is the "short" side by mutual projection (`ProjectInside`), verify the short edge lies on the long one at **23 sample points** each within Tolerance. Action: split the long edge at the projection param (`ShapeAnalysis_TransferParametersProj::TransferRange`), then `FixDummySeam` (:4213) removes the doubled pair: combine end vertices (`CombineVertex 1.0001`), copy REVERSED pcurves from the removed twin onto the survivor (`CopyReversePcurves`), stitch neighbors. `FixTails` (:4314, off unless `myMaxTailWidth>=0`) is the generalized spike remover — predicate `CheckTail` (SA_Wire.cxx:2347) bisects the tail extent with tolerance rails `width+{0.5,1.0,1.5}*Confusion` and returns up to 2 split parts per edge.
7. `FixSelfIntersection` (:1083) — three sub-passes:
   a. `FixSelfIntersectingEdge(i)` (:2708): predicate `CheckSelfIntersectingEdge` (SA_Wire.cxx:1269) — `Geom2dInt_GInter` on the pcurve against itself, domain tol **1.0e-10**; only intersections with a `Middle` transition count; points inside either vertex tolerance sphere are ignored. Fix (up to **30 iterations**): if `myGeomMode` try `RemoveLoop` (:2283) — cut params `[t1-dt, t2+dt]`, `dt = 0.1 * GAC.Resolution(prec)` (tolfact=0.1), replace loop by a 2-pole degree-1 null patch, concatenate (C0 pcurve), accept only if resulting SameParameter tol `newtol <= max(prec, oldTol)`; else grow nearest vertex tol to `1.001*sqrt(min(d²(V1,pint), d²(V2,pint)))` if `< MaxTolerance`, else FAIL. RemoveLoopMode=1 instead splits the edge at the loop (insert vertex).
   b. `FixIntersectingEdges(i)` adjacent pairs (:2966): predicate (SA_Wire.cxx:1360) intersects the two pcurves (num==1 swaps operand order — Geom2dInt is asymmetric, must match BRepCheck); guards: params clamped to range ±PConfusion; `pint = 0.5*(pi1+pi2)`, `error = 0.5*|pi1-pi2|`; intersection "real" iff `dist² > tolt²` (`tolt = min(tolVtx, max(tolEdges, myPrecision))` — the :86 trick: fix even if vertex tol already covers it, because FixLacking may later SHRINK vertex tol) or a lacking edge would be inserted there (`isLacking`: 2d end gap ≥ `2*max(URes(tol),VRes(tol))`). Fix ladder: (1) try growing EDGE tolerances instead of vertex when local deviation `te = rad + ComputeLocalDeviation` (max distance of 10 interior samples to the chord line) is smaller — factor **1.000001**; (2) if `myTopoMode` cut edges back to the intersection param (`ShapeFix_SplitTool::CutEdge`), move vertex to `pint`, tol `1.001*rad`; (3) else vertex tol := `1.0001*(d(pnt,pint)+rad)`; whole-edge-consumed → DONE3/DONE4 → caller removes the edge from the wire and restarts the scan.
   c. `FixIntersectingEdges(i,j)` non-adjacent + `ShapeFix_IntersectionTool::FixSelfIntersectWire` (IntersectionTool.cxx:1029): Bnd_Box2d prefilter per edge; for each Middle/Middle crossing: if near an existing vertex (`dist < MaxTolVert`) grow that vertex (`1.00001`) and `CutEdge`; else make a NEW vertex at `mid(pi1,pi2)` with tol `max(1.00001*|pi1-pi2|/2, Confusion)` and `SplitEdge1` BOTH edges (cap **NbSplit < 30**); Middle/End crossings reuse the end vertex of the other edge; End/End → `UnionVertexes`. Segment (overlap) intersections handled analogously (:1289). Result may leave the wire as several closed sub-loops → `SplitWire` in Face::Perform (NbRemoved → `StatusRemovedSegment`).
8. `FixLacking(i)` (:3617) — the 2d gap-closer, run LAST. Predicate `CheckLacking` (SA_Wire.cxx:1711): vertices already merged in 3d (`BRepTools::Compare`) but pcurve ends separated: `myMax2d = |p2d2-p2d1|`, fire iff `myMax2d >= tol2d = 2*max(URes(tol), VRes(tol))`; estimated 3d cost `myMax3d = tol * myMax2d / tol2d`; DONE2 marks "back-going" gap (angle(v12, tangent) > **0.9*PI**) — zigzag, don't insert an edge. Fix decision tree (:3719 comments): (a) try **bending** both pcurves (`TryBendingPCurve` — clamp end pole of the BSpline pcurve to the mid-gap point, re-FixSameParameter, accept if resulting tol beats current); (b) `inctol < Precision` → grow vertex tol; (c) `myTopoMode` and 3d gap real (`dist3d² > 1.25*tol0²`, not DONE2) → insert a **long 3d edge** replacing the fat vertex by two new small vertices; (d) not degenerate spot (`!IsDegenerated(p2d1,p2d2, 2*tol, 10.)`) and `inctol < MaxTolerance` → grow vertex tol `1.001*inctol`; (e) else insert **degenerated edge** (if `d(pV,pm) <= tol`, pm = surface value at mid-2d) or **closed edge** — straight `Geom2d_Line(p2d1→p2d2)`, range `[0, dist2d]`, 3d curve built by `ShapeBuild_Edge::BuildCurve3d` unless degenerate. After bending: re-run FixSelfIntersectingEdge on both + FixIntersectingEdges (bending can create the intersection it fixed, :s3).
9. Always: per-edge `ShapeFix_Edge::FixVertexTolerance` (grow-only cover of ALL curve representations' endpoints: `toler = max(1.0000001*sqrt(max_i d²), edgeTol)`, SA_Edge.cxx:568) + `UpdateWire()` (re-resolve every edge through the ReShape context; a replaced edge may expand into several).
10. `FixClosed(prec)` (:1304) = FixConnected(1) + FixDegenerated(1) + FixLacking(1) across the last→first junction.

### Gap fixers proper: `ShapeFix_Wire_1.cxx`
`FixGaps3d/FixGaps2d` (:76/:101): loop `i = (closed?1:2) .. NbEdges` twice — first pass `FixGap3d(i, convert=false)` only if `myFixGapsByRanges`, second pass always `FixGap3d(i, true)`.
- `FixGap3d(num, convert)` (:154): gap = `d(C1(clast1), C2(cfirst2))`; no-op if `<= Precision()` (and !convert). **Ranges mode** (convert=false): unwrap Trimmed/Offset to basis curves; widen search domains (BSpline/Bezier → full natural domain; Line/Parabola/Hyperbola → extend by `10*(l-f)` on the open side; Circle/Ellipse → `[0, 2π]`; same-edge closed circle → extend by `π - |Δparam|/2`); then in order (1) project shared-vertex mean point on both curves (`GeomAPI_ProjectPointOnCurve`), (2) `GeomAPI_ExtremaCurveCurve` on the leftover domains preferring true intersections (`d < Confusion`) nearest the old ends, (3) accept candidate iff `d(p1,p2) <= gap` AND both params moved > PConfusion AND at least one lies strictly inside its old range — then re-trim ranges (periodic-aware `AdjustOnPeriodic3d`). **Convert mode**: curves → BSpline (`GeomConvert`, conics via `Approx_Curve3d(preci, C1, maxseg 9, maxdeg 1000... actually (9,1000)=degree,segments)`), degree raised to ≥2, then **pin the end pole to the shared vertex point** (`bsp->SetPole(1|NbPoles, vpnt)`); edges rebuilt with tol Confusion, NM vertices preserved. Vertices replaced by fresh Confusion-tol copies.
- `FixGap2d(num, convert)` (:893): same skeleton in UV; working precision `preci = Precision::PConfusion()` (pure-2d criterion); intersection first (`Geom2dInt_GInter`, tolint = PConfusion, incl. segments), then extrema, then point projections (with both-inside/both-outside disambiguation via mean-point re-projection); candidates crossing the surface bounds are clipped against the UV rectangle (bounds from surface or `BRepTools::UVBounds ± preci` if infinite); convert mode pins end poles to `mpnt = mid(cpnt1, cpnt2)`. Seam edges are skipped (FAIL1).

### `FixShifted` (ShapeFix_Wire.cxx:1661) — period normalization
For U/V-closed (or revolution-with-periodic-basis) surfaces. Walk consecutive edge pairs; if the 2d jump `|Δ| > Range - 0.2*Range` → shift E2's pcurve by `AdjustByPeriod` (never move across a degeneracy in the matching axis — `DegeneratedValues` picks isDeg=1(U)/2(V)); if `0.2*Range < |Δ| < 0.8*Range` mark partial (stop=n2). Bi-meridian case (sphere cut by two meridians through both poles): detects opposing rotations `rot1*rot2 < 0`, `|scl| > 0.1*period` and shifts the span between degeneracies by the wire's estimated width (`deep` min/max over 6 sample points), `dx = AdjustToPeriod(deep, PConfusion, period+PConfusion)`. Second phase: bounding box of all pcurve starts/mids; if wire center is > half a period off surface mid (`AdjustByPeriod(mid, SMid, Range)`) — shift the WHOLE wire's pcurves (DONE2). Pcurves are `Transformed` COPIES (`ReplacePCurve`) because several edges may share one pcurve (OCC208). `UpdateEdgeUVPoints` re-stamps cached UV points after every shift.

### `FixMissingSeam` (ShapeFix_Face.cxx:1722)
Surface U- or V-closed (BSpline must already be periodic). Per wire, static `CheckWire` (:1652): 2d closure vector `vec = Σ (c2d(l)-c2d(f))`; wire is "open in U" iff `||vec.X()| - URange| < 0.1*URange` (sign gives direction), same for V. Pair up two open wires (w2 with opposite sign; equal sign → reverse one, preferring the all-degenerate one). Single open wire → synthesize the opposite bound as a **degenerated edge wire** (sphere: v=±π/2 line over 2π; degenerate torus: `phi = acos(-R/r)`; BSpline with collapsed side: detect via `Value(SUF,SVF)≈Value(SUF,mid)`). Orientation sanity: min-coordinate wire must run positive-U (U-closed) / negative-V (V-closed), else reverse both. Torus (both-closed): extra AdjustByPeriod of w2 (and holes) ALONG the seam direction, and split-parameter `uf/vf` chosen at `mid - period/2` to dodge extra intersections; better: prefer a param where edge ends of BOTH wires coincide (`foundU=2`). Finally builds a 1×1 `Geom_RectangularTrimmedSurface(surf, uf, uf+URange, vf, vf+VRange)` grid and runs `ShapeFix_ComposeShell` with `ClosedMode=true` to actually cut in the seam; then removes null wires/faces ComposeShell may create (`FixSmall(true, preci)` per wire, `FixSmallAreaWire(true)` if >1 face).

### `ShapeFix_Edge::FixSameParameter` (ShapeFix_Edge.cxx:798) — dual-candidate acceptance
If !SameRange → `TempSameRange(edge, PConfusion)` (GeomLib::SameRange each pcurve to the 3d range). If edge wasn't SameParameter: run `BRepLib::SameParameter` on a COPY; measure both the copy (`BRLTol/BRLDev`) and the original's raw deviation (`ShapeAnalysis_Edge::CheckSameParameter`, 23 control points via `BRepLib_ValidateEdge`); keep whichever is tighter (copy wins → `CopyPCurves` back). Vertex tolerances RESTORED to `max(maxdev, oldTol)` (BRepLib inflates them); edge tol := maxdev if larger.

### `ShapeAnalysis_Surface` — the projection/singularity substrate
- `ComputeSingularities` (:181): cone → 1 (apex, preci 0); torus → 1 or 2 (preci `max(0, R-r)`); sphere → 2 poles (preci 0); Bounded/Revolution/Offset → 4 *candidate* degenerate sides, `preci_i = max(side chord, dist(sideMid, corners))` — a side is "degenerate at tolerance p" iff `preci_i <= p`. Sorted ascending by preci. All degeneracy predicates (`IsDegenerated(P3d,preci)`, `DegeneratedValues` = min-gap singularity, `ProjectDegenerated` = snap pcurve points at a pole to the neighbour's non-iso coordinate; whole-curve-degenerate → distribute evenly :512).
- `IsDegenerated(p2d1,p2d2,tol,ratio)` (:549): 3d collapse (`max3d = max of 3 pairwise dists of ends+mid <= tol`) AND 2d extent large in resolution units (`(du/RU)² + (dv/RV)² > (ratio*max3d)²`); callers use ratio=10.
- `SurfaceNewton` (:1065): 25-iteration 2nd-order Newton from a previous UV; bail thresholds `nrm2 < 1e-10`, `|D| < 1e-10`, step accept `|du|+|dv| <= max(1e-12, (U+V)*1e-15)`, must not diverge (`rs2 <= rsfirst2`), residual must be normal (`rs2 - (rs·n)²/n² <= Confusion²`); returns 2 ("suspect") if `n² < 0.01*ru²*rv²` (near-collapsed frame — the q6 attractor guard).
- `NextValueOfUV` (:1164): Newton seeded by previous point; falls back to full `ValueOfUV` near C0 knots or when res==2/gap>maxpreci and iso-projection beats it.
- `ValueOfUV` (:1245): analytic `ElSLib::Parameters` + `AdjustByPeriod` to domain middle for plane/cyl/cone/sphere/torus; freeform: cached `Extrema_ExtPS` over bounds extended by `min(myDelt, Resolution(preci))`, then Newton polish, then `UVFromIso` (:1522) fallback (project on 4 bound isos, best of), exception → midparam. `myGap` always records achieved distance — callers treat projection as *never failing*, only more or less precise.

## DATA STRUCTURES

- **ShapeExtend_WireData** — ordered edge list detached from TopoDS_Wire; allows temporary invalid states (gaps, unordered, duplicate edge occurrences), seam flags `IsSeam(i)`, index add/remove/set; `Wire()` rebuilds. Everything wire-level operates on this, not on TopoDS.
- **ShapeBuild_ReShape (Context)** — global replace/remove map with `Apply` resolution; records vertex/edge/wire substitutions so shared topology stays consistent across faces; `UpdateWire()` re-resolves the SBWD through it (one edge may expand to a wire of split parts). Same role as our combine-time rewrite maps.
- **Status word** — one `int` per fix family, bit-encoded `ShapeExtend::EncodeStatus(OK|DONE1..DONE8|FAIL1..FAIL8)`; predicates report *what kind* of problem, actions report *which remedy* was applied. `LastCheckStatus`/`LastFixStatus` steer caller branching (e.g. FixSelfIntersection removes edge on DONE3/DONE4).
- **ShapeAnalysis_WireOrder** — array of per-edge (start,end) 3d and/or 2d points + greedy chain solver; `Ordered(i)` returns original index (negative = reverse edge); `SetChains(gap)` clusters into gap-bounded chains; `KeepLoopsMode` keeps separate loops contiguous.
- **ShapeAnalysis_Surface** — caches: adaptor, 4-slot singularity table (`myP3d/myFirstP2d/myLastP2d/myFirstPar/myLastPar/myUIsoDeg/myPreci`, sorted), bound isos, closure values `myUCloseVal/myVCloseVal` + `myUDelt/myVDelt` (= range/20), one persistent `Extrema_ExtPS`, `myGap` (last projection error).
- **ShapeAnalysis_Wire** — holds SBWD + face + `ShapeAnalysis_Surface` + precision; outputs `myMin2d/myMax2d/myMin3d/myMax3d` (measured gaps) alongside statuses — fixers read these instead of re-measuring.
- **ShapeFix_IntersectionTool** — context + preci/maxtol; per-edge `Bnd_Box2d` map for the O(n²) non-adjacent pass.

## INVARIANTS

1. **Order dependency is absolute**: reorder → small → connected → edge-curves → degenerated → self-intersection → lacking. Each stage assumes prior ones (FixLacking assumes vertices already 3d-merged by FixConnected; FixSelfIntersection assumes correct order; FixShifted must precede FixDegenerated; FixDegenerated before FixLacking — hxx:264, NOTE :3497).
2. **Tolerances only grow** during a fix (except FixSameParameter which *restores* vertex tols after BRepLib inflation, and FixGap convert-mode which resets rebuilt entities to Confusion because geometry now passes exactly). Consistent with kb/occt_tolerance-model.md.
3. **Tolerance-first, topology-last**: every intersection/gap fix tries (a) grow tol, (b) local geometry edit, (c) topology edit — in that order; topology edits gated by `ModifyTopologyMode` (default FALSE; forced true only for free faces/wires at Shape level — a face inside a shell must not change shared edges; :j6 "do not cut edges because of influence on adjacent faces").
4. **Analysis never mutates**; fix actions re-run the predicate afterwards when the fix could re-introduce the defect (self-int after RemoveLoop, after bending; reorder after small-edge removal; `%15` "repeat until fixed").
5. Iterate **downward** when removing (FixSmall), restart scan after edge removal (FixSelfIntersection resets `num`), refresh context after each replacement (`UpdateWire`).
6. 2d and 3d verdicts are cross-checked at every decision: connected in 3d but open in 2d → lacking; closed in 2d but open in 3d → gap3d; 2d jump ≈ period → shifted not open; both → seam missing. One-sided evidence never triggers topology edits.
7. Degenerated edges are *first-class exemptions*: skipped by small/gap/notch/self-int fixes; their pcurve presence/absence decides removal vs repair.
8. Projection never hard-fails: ValueOfUV always returns a point + `myGap`; callers compare gaps rather than branching on success.
9. Everything periodic goes through `ShapeAnalysis::AdjustByPeriod/AdjustToPeriod` against a *reference* (domain middle, previous point, other wire) — never raw mod.
10. Pcurves are copied before transforming (several edges may reference one pcurve — OCC208).

## PITFALLS

- **Asymmetric 2d intersector**: `Geom2dInt_GInter(C1,C2)` ≠ `(C2,C1)`; OCCT swaps operands for the last-first edge pair (`num==1`) to stay consistent with BRepCheck (:64, SA_Wire.cxx:1433). Any parity between checker and fixer must intersect in the same operand order.
- **Fixing below the intersector's floor**: domain tol 1e-10 is absolute; huge-model UV (e.g. unscaled mm vs m) can starve it. Precision-scaled inputs assumed.
- **Vertex tol can mask self-intersections that later reappear** when FixLacking *shrinks* effective closure (:86) — hence `tolt = min(tolVtx, max(tolEdge, prec))`, i.e. deliberately test at a tolerance SMALLER than the vertex's.
- **RemoveLoop produces C0 pcurves** and requires SameParameter re-verification; accepted only if resulting tol ≤ max(prec, old) — otherwise the loop is left and the vertex is fattened instead.
- **Small-edge removal with distinct vertices re-opens the wire** — must be immediately followed by FixConnected at the removal index (n<=NbEdges? n : 1 — the :43 last-edge wrap bug).
- **Splitting at a singularity** is mandatory when a projected pcurve crosses a pole (FixAddPCurve DONE2 branch); otherwise SameParameter blows up. Snap-to-existing-vertex first if within `1.01*tolV`.
- **Bi-periodic surfaces**: reorder must use miscible 2d+3d mode; 2d-only ordering on a torus chains across the seam.
- **FixShifted degeneracy axis lock**: shifting is forbidden along the axis of a nearby degeneracy (isDeg 1|2) — else pole-adjacent edges get period-teleported (torCuts.sat :abv 29.08.01).
- **CheckDegenerated false positive**: an edge whose ends collapse but whose 3d midpoint is far from the pole is a CLOSED edge, not degenerate (trj3_as1 :979).
- **FixLacking zigzag guard**: inserting an edge when the gap points backwards (>0.9π vs tangents) creates a self-intersection; grow tol instead (:81 "don't add back-going edges").
- **Auto-precision**: running gap fixes at precision > half the min edge length erases legitimate small edges — clamp first (OCC21623).
- **Seam pcurve order depends on wire orientation** (FixSeam note hxx:359-372): correct only if wire is FORWARD-composed; extracting with composed orientation silently swaps FWD/REV pcurves.
- **BRepLib::SameParameter may be WORSE than doing nothing** — always dual-candidate and keep the better (#81 rln).
- **ComposeShell fallout**: FixMissingSeam's splitter can generate null wires/micro faces; must sweep with FixSmall + FixSmallAreaWire afterwards (bug30052_4).
- **`Context()->Apply` staleness**: after any Replace, edges held by index in SBWD are stale; FixConnected refreshes slot n-2 mid-loop; forgetting this yields double-welds to dead vertices.
