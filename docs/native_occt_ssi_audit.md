## Coverage regression SSI-003: two closed components in one candidate cell

The exact fixture is preserved in [fixtures/two_closed_loops_one_cell.json](fixtures/two_closed_loops_one_cell.json), using the native `NurbsSurface::jsonload` schema. The test `Surface Section Native::Two Closed Loops Inside One Knot Cell` constructs it independently and writes an execution copy before calling SSI, so an exception cannot erase the input evidence.

Both surfaces have degree four in each parameter over `[0,1]^2`. The first is `A(u,v)=(u,v,0.1*(u*u+v*v))`; the second adds `100*F1(u,v)*F2(u,v)` to its height, where each `Fi=(u-ci.x)^2+(v-ci.y)^2-.025^2`, with centers `(.31,.32)` and `(.43,.42)`. Each circle lies strictly inside the single initial cell `[.25,.5]^2`. The intersection has exactly two disjoint closed components. The test checks both components separately, not only the nonempty result or aggregate length, and verifies radius in UV and both world lifts.

**Specific source comparison.** `IntPatch_PrmPrmIntersection.cxx:2560` retains separate approximate section chains, and 2680-2724 retries different starts within each chain. Our `seed_cell_pair` has no equivalent branch accounting: finding one root currently consumes the whole candidate rectangle. That shortcut can hide another component. OCCT's sampled candidate generation itself is not a mathematical completeness proof, so the regression should also be checked through the separate oracle instead of being declared correct solely by analogy.

**Correction invariant.** A successful Newton point is a seed, not a coverage certificate. A candidate may be excluded only by conservative separation, or marked covered after proving that every root in it belongs to an already traced branch. A parameterized interval-Newton/Krawczyk contraction can establish one continuous root graph: choose one free parameter, enclose the other three-variable Jacobian, and establish existence/uniqueness over the free interval. Boundary cells need boundary-event accounting because a graph can leave and reenter a rectangle. Fixed extra subdivision levels would merely move the original failure to a smaller geometric scale. This regression has been added but not yet executed; coverage correction remains pending its preserved result.

**Read-only certificate design.** Write the three position equations as `F(z,t)=0`, where `t` is one selected surface parameter and `z` comprises the other three. For a candidate interval `T` and an enclosing three-dimensional box `Z`, a parameterized Krawczyk enclosure is `K = z0 - R*F(z0,T) + (I-R*Jz(Z,T))*(Z-z0)`, with `R` the inverse midpoint Jacobian. Strict inclusion `K ⊂ interior(Z)` plus a contraction bound proves existence and uniqueness for every `t ∈ T`. A nonzero determinant alone proves neither existence across the interval nor connected candidate coverage. The enclosure may use a larger `Z` than the original candidate to avoid losing a branch at an artificial subdivision edge, but it must remain within valid surface domains; otherwise a graph that exits and reenters a domain can represent disconnected retained components. Such cells require constrained boundary-event roots and subdivision, or a separate certified monotonicity argument.

For rational patches, derivative enclosures must use homogeneous numerator/denominator polynomials and a positive denominator bound: `d(N/W)=(N'W-NW')/W²`. Adjacent Bernstein control differences bound `N'` and `W'`; translating the Euclidean control points near the candidate reduces cancellation without changing derivatives. Merely bounding differences of dehomogenized rational control points is incorrect. Initial NURBS-to-Bezier extraction and every arithmetic/subdivision operation must contribute outward rounding; the existing fixed CV-coordinate padding is not by itself a proof of accumulated rounding. Keep the candidate unresolved if these bounds cannot establish separation or one covered root graph. This is an implementation plan, not a claim that OCCT uses Krawczyk contraction or that the native certificate is already present.
