## Shared-edge provenance gap reported by the coordinating agent

OCCT's `BOPAlgo_PaveFiller.cxx:254` through its staged intersection workflow performs vertex/edge/face interference work before final face/face processing and builds split edges, common blocks and pcurves. `BOPDS_CommonBlock.hxx:35` documents the common representative edge relationship. The native `split::FaceSplit` already returns `EdgePiece` provenance, and `brep_assemble::FaceUse` accepts pieces and operand identity. At the audited checkpoint, `brep_boolean::partition` retained only `.brep`, and `select` supplied neither provenance nor operand identity. This forces assembly to rediscover correspondence geometrically.

A fix must carry a persistent partition result containing its BRep and edge provenance, update mappings after each later face split, and retain section/source-edge identity through assembly. The coordinating agent traced `split.cpp`: geometry/topology pools are append-only; `replace_wires` changes edge uses without compacting the edge pool. Initialize each original edge's source identity, retain old records, and resolve each returned piece through its prior parent edge. A new cut keeps its section identity; a child of an earlier cut inherits that identity. Merely concatenating local parent indices loses the original provenance even though pool indices remain stable.

## XOR edge adjacency review

`BOPTools_AlgoTools.cxx:994`, `GetFaceOff`, computes face directions through `MinStep3D`/`GetFaceDir`, measures signed angles around an edge-derived reference axis, and selects the next face. It rejects unresolved angle differences using `Precision::Confusion()`; same-face occurrences receive special handling. The source therefore does not require exactly two face uses globally at every result edge: several material regions can share that geometry, and shell construction must choose the appropriate adjacent uses.

Independent review of the native angular sign: for a +Z tangent and the occupied XY quadrant `x>0,y>0`, the `y=0` boundary has reversed edge use and inward-face direction +X. Its +Z angular axis selects the `x=0` face at +Y. The reciprocal forward use rotates around -Z back to +X. This is the correct material-sector pairing for transverse XOR. Each constructed shell must still have closed balanced incidence. Native midpoint derivative directions require a constant angular ordering along each split interval, and do not reproduce OCCT's near-face treatment of tangential contacts. A machine-epsilon-only angle threshold is insufficient justification for near-tangent ordering at modeling tolerance; that divergence was reported to the coordinating agent.

After that slice, outward concave/mixed neighborhoods can reuse the same section/partition machinery on face/tube and tube/tube pairs. A native exact wall between rational curves with different weights can preserve linear ruling parameters by using the common product denominator `A_w(t) B_w(t)`, with homogeneous rows `A_h(t) B_w(t)` and `B_h(t) A_w(t)` on common Bezier intervals. Ordinary homogeneous row interpolation preserves straight ruling geometry but generally changes its parameter, so it is insufficient for sharing existing straight connector pcurves without repair. Closed boundary curves need one connector used twice with two seam pcurves; inner wires need their composed reversed boundary orientation. Original and displaced support faces have opposite material orientation, and the sign of thickness determines which is reversed.
